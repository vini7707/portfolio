# Vikas Srivastava — Portfolio

One-page portfolio for a frontend developer, built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

Update the project list and contact details in `src/main.jsx` before publishing.

## GitHub Pages

The workflow in `.github/workflows/deploy.yml` builds the site and publishes it to GitHub Pages whenever `main` is updated. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.
